## 🌐 Deployment to GitHub Pages

To deploy this portfolio live on GitHub Pages:
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Build premium QA portfolio website for Nadiya Sherief"
   git branch -M main
   git remote add origin https://github.com/nadiyasherief186arc/NadiyaSherief-Portfolio.git
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &gt; **Source**, select **Deploy from a branch**.
4. Set branch to `main` and folder to `/(root)`, then click **Save**.
5. Your portfolio will be live at:
   `https://nadiyasherief186arc.github.io/NadiyaSherief-Portfolio/`
